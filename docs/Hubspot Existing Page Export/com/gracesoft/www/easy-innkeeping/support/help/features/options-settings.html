Features

 

Options Settings

 

                    Different settings in Easy InnKeeping ASP can be customized to suit your preference. To access the Options screen, select Features  >  Options Settings in the main menu. The Options screen is displayed as shown below.                

Bill Setting

 

                    The Bill Settings can be set to can be set to allow the following:                

Show Daily Rates on Bill: Selecting the following option will allow nightly rates to print in the bill. This is useful when there is more than a single rate applies to a reservation and they are broken down clearly in the bill for the guest.                

Print Whole Credit Card Number on Bill: For security reasons, only the last few digits of the credit card is printed on the bill. But if you choose to view the entire credit card number on the bill, click on the check box to enable this feature.                

Show Tax Breakdown on Bill: Selecting this option will allow you to view the breakdown of different taxes in the bill, if it is applicable.                

Page Setting

 

Set Default Home Page To: The default page can be set, so the screen selected here will always be the screen that appears every time you close a screen. This default can be any one of the following options:                

                    Weekly Availability Chart                

                    Monthly Availability Chart                

                    Daily Availability Chart                

                    Room Type Chart                

                  Default View (Reservation list for the                

Set No of Rows to be displayed: This will determine the number of rows (rooms) that will displayed in the Availability Charts. For example, you can choose to display 15 rooms at a time in the Availability Chart. To view rooms from room 16 onwards, click on the  button in the lower right portion of the screen. Use the navigation buttons provided to move from one set of rooms to the other.                

Chart Settings

 

Display Charts by: This option allows you to display room details in the Availability Charts based on the following selections                

  • Unit Name: Displays the Unit Name in the Availability Chart. If the reservations are unique to each unit name, use this option
  • Unit No: Displays Unit No in the Availability Chart. Select this option if the reservations are based on unit number.
  • Unit Type: This option displays the unit name based on unit type in the Availability Chart
  • Unit No & Unit Name: This option displays both unit number and unit name in the Availability Chart.
  • Unit Name & Unit Type: This option displays both unit name and unit type in the Availability Chart.

Sort Charts by: This options sorts the Availability Charts based on Unit Name or Unit Number.                

Set Default Reservation to: This selection allows you to choose the Quick Reservation or the Full Reservation screen as your default screen while double clicking to open a reservation from the Reservation Charts. The Quick Reservation screen displays all the required details of the reservation in a single screen. The Full Reservation screen has a detailed view of the reservation in different tabs.                

Set Name to be displayed: This feature allows you the option of choosing the First or the Last Name of the guest while displaying their reservation in the Charts. For example, if you choose ‘Last Name’ John Smith’s reservation will be displayed as ‘Smith’ in the reservation charts.                

Set Status after Check Out:

Date Settings

 

Use this date format: Date through throughout the application will be displayed based on the format selected in this list. Dates can be of the following formats.                

  • mm/dd/yy (month/day/year)
  • dd/mm/yy (day/month/year)
  • yy/mm/dd (year/month/day)

Show year in four digit: When this check box is checked on, the year will be displayed in four digits. For example, as in 2007.                

Set default Check-In time: The time selected here will be set as Check In Time in the Reservation screen.                

Set default Check-Out time: The time selected here will be set as Check Out Time in the Reservation screen.                

Night Audit Settings

 

                    Run Night Audit Report every night at: A fixed time to run the Night Audit Report every night (EX: 11.00 PM) can be set in this screen. The Night Audit report can be run each night at the fixed time and handed over to the manager of the property. This will help the manger keep track of the income generated before that night.                     If the Night Audit options are set, and runs a night audit report, close balance will show with the in coming amount for that day only after the passing system day and time.                     The Night Audit can be run at anytime if the time is not set in this screen.                

Condo Owner Settings

 

Enter % of Amount: This is applicable only to users with Condo Module. This is the percentage of the reservation that will be allocated to the Condo Owner
