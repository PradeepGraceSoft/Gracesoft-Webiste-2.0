# Full-site migration phase gates

## Gate 0 — Readiness setup (current)

Allowed now: local documentation, read-only public research, read-only HubSpot inspection after CLI access is repaired, and preserving an owner-provided export as read-only reference. No remote changes.

Exit criteria: complete URL inventory; verified page source; status/canonical/indexability; analytics and backlink evidence; forms/CTA map; claims/media register; migration risks; reviewers assigned.

## Gate 1 — Audit approval

Deliver the inventory and evidence-backed SEO, content, UX, performance and conversion audit. Owner approves the audit priorities before migration architecture is approved.

## Gate 2 — Migration design approval

Deliver proposed sitemap, one-to-one URL migration map, content ownership, design system, HubSpot architecture, redirect candidates, QA strategy, backup/rollback plan. Owner approves before implementation expands beyond the current local homepage scope.

## Gate 3 — Local implementation approval

Implement approved page batches in isolated local source. Review diffs, run the available local checks, and record unrun checks honestly. No remote upload, sync or draft creation is included.

## Gate 4 — Isolated development upload approval

Requires separate explicit approval naming the HubSpot account, uniquely named test theme, exact unpublished test page(s), and permitted operations. No production page, shared asset, setting, menu, form, redirect or active theme change.

## Gate 5 — Production release approval

Requires a second explicit approval naming exact production pages and operations. Before approval: preserve current pages, validate forms without production test leads, confirm redirects, metadata, analytics, accessibility, responsive behavior, rollback and monitoring. DNS/domain changes require their own explicit approval.

## Current gate

**Gate 0 in progress.** Audit and architecture approvals have not been granted. Project instructions say the current local implementation scope is homepage-only. The user has requested full-site migration setup, so planning artifacts are now prepared locally, but implementation of additional pages remains pending Gate 1 and Gate 2 review.
