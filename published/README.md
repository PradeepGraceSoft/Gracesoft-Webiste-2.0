# Approved release packages

This folder is intentionally empty. It is reserved for a reviewed local release package after the owner approves the isolated test target.

Files placed here are still local. Copying files here does not upload or publish them. Do not run HubSpot upload, watch, sync, staging, page-create, or publish commands without separate explicit approval naming the exact account and target.

Production homepage replacement requires a second approval naming `https://www.gracesoft.com/` and a reviewed backup and rollback plan.
