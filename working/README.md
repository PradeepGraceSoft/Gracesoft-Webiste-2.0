# Atelier local work

This folder contains the selected Atelier homepage draft and its local review assets. Nothing here uploads to HubSpot.

```text
working/
  theme/Atelier Theme/  Editable HubSpot-compatible theme source
  preview/                              Standalone browser preview and QA evidence
```

Open `preview/home-v2-atelier-content.html` in a browser. It is a static approximation, not a HubSpot HubL render. See `../docs/atelier-content-review.md` for content sources, checks and remaining review items.

Portal-validation records and read-only source placeholders remain outside this folder because they document project safety and provenance, not alternate visual themes.
