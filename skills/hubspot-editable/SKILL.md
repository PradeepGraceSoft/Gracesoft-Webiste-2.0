# HubSpot page editing standards

Use when changing HubSpot theme source or page modules.

- Put page content in editor fields and a drag-and-drop area. Do not lock marketing copy in shared template markup.
- Give modules clear labels and sensible default content. Expose headings, text, links, images, alt text, card lists and FAQ fields.
- Keep global design settings separate from page-specific copy.
- Use HubSpot-supported module metadata, fields, HubL and template composition. Validate with the currently supported CLI and account after approval.
- Test editor changes to a heading, card, image, CTA and FAQ on an isolated approved page.
- Page-field changes use the HubSpot editor. HubL, CSS, JS and schema changes require theme-source updates.
- Keep shared headers, footers, menus, forms and global modules untouched unless scope explicitly includes them.
- Never upload, sync, watch, create a remote draft or publish without written approval naming exact target.
